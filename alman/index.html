One-time setup

The ledger lives in the private repo oruc47/alman-data. This page needs a token to read and write it. Paste it once per phone — it stays in this browser only and is never committed anywhere.

  1. Create a private repo named alman-data.
  2. Make a fine-grained token at github.com/settings/personal-access-tokens: resource owner oruc47, Only select repositories → alman-data, permission Contents: Read and write.
  3. Paste it below.
